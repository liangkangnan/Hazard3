这是Eclipse IDE的工程模板，里面是一个简单的通过串口打印“hello”的程序。

1.下载Eclipse
https://www.eclipse.org/downloads/packages/release/2024-12/r/eclipse-ide-embedded-cc-developers

2.下载RISC-V编译器
https://github.com/xpack-dev-tools/riscv-none-elf-gcc-xpack/releases

3.下载windows build tool
https://github.com/xpack-dev-tools/windows-build-tools-xpack/releases


通过Eclipse的File->Open Projects From Files System选择本目录即可打开工程。
